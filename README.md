## Odoo apps

**[odooapps](https://github.com/odoomates/odooapps)**: our main collection of free modules, one branch per Odoo version from 10.0 to 20.0. All open source (LGPL-3 or AGPL-3) and also on the [Odoo Apps Store](https://apps.odoo.com/apps/modules/browse?author=Odoo%20Mates).

| Area | Apps |
|---|---|
| **Accounting** | Financial reports (balance sheet, profit and loss, general ledger, trial balance, aged partner balance, tax report), assets, budgets, loans and leases, bank statement import, follow-ups, recurring payments, fiscal years, currency rates and revaluation |
| **Access and security** | Access Manager (configure what each user sees from the real menu tree, preview as a user), user audit log, menu restriction |
| **Automation** | Automation Studio: visual workflows, approvals and templates |
| **Productivity** | Excel export of any report, WhatsApp, documents, e-signature, print templates |
| **Tools** | Remove Data: clear the transactions of a test database in one go |
| **Learning** | Hospital Management: the module built step by step in the tutorials |

**[hr](https://github.com/odoomates/hr)**: free HR and payroll apps for Odoo.

## Browser extensions

Chrome and Firefox extensions that work on any Odoo database:

- **[odoo2xl](https://github.com/odoomates/odoo2xl)**: Odoo reports to real Excel spreadsheets (Odoo 16 to 20).
- **[oofind](https://github.com/odoomates/oofind)**: visual search for Odoo 19+: one-click filters with counts, a domain builder, and why a record is not in the list.
- **[odex](https://github.com/odoomates/odex)**: run ORM calls in Python syntax on any Odoo page and inspect the result.
- **[odoo-import-export](https://github.com/odoomates/odoo-import-export)**: import, export and analyze any Odoo model from the browser (Odoo 16 to 20).
